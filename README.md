## 題目選定：移動秘書
網頁版自動摘要會議記錄，利用IAI ASR識別音檔，整理摘要並規劃未來進度，設計自動化功能如：將整理好的摘要傳送至LINE記事本或是進度規劃整合進行事曆中，讓使用者減少繁瑣的程序，後續可以設計一個系統將這些整理好的任務當作提示詞去讓該系統完成目標。
